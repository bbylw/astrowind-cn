## 表格

| 文件                    | 作用               | 是否常改 |
| ----------------------- | ------------------ | -------- |
| `src/config.yaml`       | 站点信息与默认 SEO | 是       |
| `src/navigation.ts`     | 菜单与页脚         | 是       |
| `src/content.config.ts` | 文章字段校验       | 很少     |
| `astro.config.ts`       | 集成、字体、图片   | 偶尔     |

## 代码块

```yaml
i18n:
  language: zh-CN
  textDirection: ltr
ui:
  theme: 'system'
```

代码高亮跟随站点主题：亮色用 `github-light`，暗色用 `github-dark`，配置在 `astro.config.ts` 的 `markdown.shikiConfig` 里。
